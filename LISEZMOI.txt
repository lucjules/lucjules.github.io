MES COURS IUT
=============

Ouvre "index.html" (double-clic) dans ton navigateur : c'est l'accueil général.
Il mène aux 5 matières, et chaque matière a sa propre page d'accueil avec ses chapitres.

index.html                      accueil général
algo/index.html                 Algorithmique : cycle1.html, cycle2.html
systeme/index.html              Système : intro-systeme.html
sql/index.html                  Bases de données : sql-requetes-simples.html
management/index.html           Management : introduction.html, chapitre1.html
maths/index.html                Mathématiques : logique, arithmetique, recurrence, second-degre, revision
                                (le code commun des 5 pages est dans maths/app.js)
assets/                         styles (un style de base + un style par matière), icône
assets/fonts/                   polices (hébergées dans le dossier, aucune connexion nécessaire)
sw.js, manifest.webmanifest     application installable et disponible hors ligne (site en ligne)
404.html                        page « introuvable »
outils/                         régénère l'index de la recherche (lancé automatiquement sur GitHub)

Notes
- Garde le dossier complet ensemble : les pages utilisent le dossier "assets".
- Aucune connexion Internet n'est nécessaire : tout, polices comprises, est dans le dossier.
- La progression est enregistrée dans le navigateur (par appareil).
- Pour la passer d'un appareil à l'autre : panneau « Sauvegarder ou transférer ma progression » en bas de l'accueil.
- Pour ajouter un chapitre plus tard : dépose son fichier .html dans le dossier de la matière
  et ajoute une carte dans la page index.html de cette matière.
  Sur GitHub, la recherche et le mode hors ligne se mettent à jour tout seuls (voir README.md).
